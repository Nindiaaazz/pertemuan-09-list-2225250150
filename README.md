## Deskripsi
Proyek ini dibuat untuk mempelajari penggunaan list atau array dalam Python dan pengolahan data numerik sederhana.

Program latihan meliputi pembuatan list, indeks dan slicing, manipulasi list, perhitungan statistik, penyaringan nilai kelulusan, dan penggunaan fungsi.

Program utama menganalisis nilai mahasiswa dengan menghitung jumlah data, total nilai, rata-rata, nilai tertinggi, nilai terendah, serta jumlah mahasiswa yang lulus dan tidak lulus.

Batas kelulusan yang digunakan adalah nilai lebih besar dari atau sama dengan 60.
